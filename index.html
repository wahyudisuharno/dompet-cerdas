Panduan Penggunaan Aplikasi

💡 Tips Mulai dari Nol:

Saat pertama dibuka, aplikasi menampilkan data simulasi. Untuk menghapusnya dan mulai mencatat keuangan Anda sendiri, klik tombol Data di menu atas → pilih Kosongkan Semua Data.

  1. Aktivasi Lisensi / Free Trial 30 Hari: Masukkan kode lisensi dari admin atau klik "Mulai Coba Gratis 30 Hari" saat pertama membuka aplikasi.
  2. Pasang di Layar Utama HP: Buka menu titik tiga di browser Chrome/Safari, lalu pilih "Instal aplikasi" atau "Tambahkan ke Layar Utama".
  3. Catat Pemasukan Terlebih Dahulu: Pilih tab Pemasukan (+), isi nominal gaji/hasil usaha, lalu simpan. Sistem otomatis menghitung batas ideal 50% Pokok, 30% Keinginan, dan 20% Tabungan.
  4. Catat Pengeluaran Harian: Gunakan tombol Isi Cepat (Quick Tags) atau isi manual sesuai pos anggaran.
  5. Backup & Ekspor Excel (CSV): Gunakan menu Data di pojok kanan atas untuk mengunduh laporan CSV atau cadangan file JSON kapan saja.
